# AI 챗봇/리뷰 자동응대 프로세스

이 문서는 개발자가 없는 조직에서도 이해할 수 있도록, AI 챗봇이 실제 업무에서 어떤 순서로 작동하는지 설명하기 위한 자료입니다. 현재 데모는 네이버 스마트스토어 리뷰 답변 자동화 흐름을 기준으로 합니다.

## 한 줄 요약

AI가 고객 문의나 리뷰를 읽고, 의도를 분류한 뒤, 회사 톤에 맞는 답변 초안을 만들고, 담당자가 확인 후 등록하는 구조입니다.

## 전체 흐름

```text
고객 리뷰/문의 발생
        |
        v
리뷰/문의 데이터 수집
        |
        v
AI가 내용 분석
- 긍정/중립/부정 분류
- 배송, 상품, 교환/환불, 사용법 등 이슈 파악
        |
        v
답변 초안 생성
- 회사 말투 반영
- 금지 표현 제거
- 고객 상황별 문장 선택
        |
        v
사람이 검토
- 민감한 건 직접 수정
- 문제 없는 건 승인
        |
        v
네이버 스마트스토어/상담 채널에 답변 등록
        |
        v
누적 데이터로 품질 개선
```

## 비개발자용 설명

AI 챗봇은 사람을 완전히 대체하는 프로그램이 아니라, 반복적인 고객 응대 업무를 먼저 정리해주는 보조 직원에 가깝습니다.

예를 들어 고객이 "배송이 늦고 포장이 찌그러졌어요"라고 리뷰를 남기면, AI는 이 내용을 부정 리뷰로 분류합니다. 그 다음 사과, 확인, 개선 약속, 고객센터 안내가 들어간 답변 초안을 만듭니다. 담당자는 이 초안을 보고 그대로 등록하거나, 실제 주문 상황에 맞게 수정합니다.

## 데모에서 보여줄 수 있는 장면

1. 리뷰 3개를 준비합니다.
   - 긍정: "배송 빠르고 상품도 마음에 들어요."
   - 중립: "무난합니다. 아직 오래 써보지는 않았어요."
   - 부정: "배송이 늦고 포장이 조금 파손되어 왔습니다."

2. AI가 리뷰를 분류합니다.
   - 긍정 리뷰: 감사와 재구매 유도
   - 중립 리뷰: 후기 감사와 개선 의지
   - 부정 리뷰: 사과, 확인, 고객센터 안내

3. 답변 초안을 출력합니다.
   - 실제 스마트스토어에는 바로 등록하지 않습니다.
   - 사람이 검토하는 안전 단계가 있습니다.

## 현재 데모 실행 명령

```powershell
.\.venv\Scripts\python -m app.main --sample
```

## 실제 업무 적용 시 구조

| 단계 | 사람이 하는 일 | AI가 하는 일 |
| --- | --- | --- |
| 리뷰 확인 | 어떤 리뷰가 중요한지 확인 | 미답변 리뷰를 모아 정리 |
| 내용 판단 | 민감 이슈 여부 판단 | 긍정/중립/부정, 배송/상품/환불 등 분류 |
| 답변 작성 | 최종 문장 확인 | 회사 톤에 맞는 답변 초안 작성 |
| 등록 | 승인 후 등록 | 승인된 답변만 등록하도록 보조 |
| 개선 | 자주 나오는 문제 파악 | 반복 이슈 통계화 |

## 회사 입장에서 기대 효과

- CS 담당자의 반복 답변 시간을 줄일 수 있습니다.
- 리뷰 답변 속도를 높여 고객 신뢰도를 개선할 수 있습니다.
- 부정 리뷰를 빠르게 발견해 배송, 포장, 상품 문제를 조기에 파악할 수 있습니다.
- 개발자가 없는 회사에서도 처음에는 반자동 방식으로 안전하게 도입할 수 있습니다.

## 안전장치

처음부터 AI가 자동으로 답변을 등록하게 만들지 않습니다. 초기 버전은 반드시 사람이 검토한 뒤 등록하는 방식이 좋습니다.

권장 단계는 다음과 같습니다.

1. 1단계: AI가 답변 초안만 생성
2. 2단계: 담당자가 승인한 답변만 등록
3. 3단계: 반복적이고 안전한 문의만 자동 처리
4. 4단계: 클레임, 환불, 법적 표현 등 민감 이슈는 사람에게 자동 전달

## 회사에 제안할 AI 부서 역할

AI 부서는 단순히 챗봇 하나를 만드는 부서가 아니라, 회사의 반복 업무를 자동화하고 데이터를 쌓아 의사결정을 돕는 역할을 합니다.

초기 우선순위는 다음과 같습니다.

1. 리뷰 답변 자동화
2. 고객 문의 유형 분류
3. 자주 묻는 질문 자동 응답
4. 부정 리뷰 및 클레임 알림
5. 상품/배송/포장 관련 반복 이슈 리포트

## 발표용 짧은 설명

"이 시스템은 고객 리뷰를 AI가 먼저 읽고 긍정, 중립, 부정으로 분류한 뒤 회사 말투에 맞는 답변 초안을 만들어주는 구조입니다. 중요한 점은 처음부터 자동 등록하지 않고, 담당자가 검토 후 승인하는 반자동 방식으로 시작한다는 것입니다. 그래서 개발자가 없는 조직에서도 위험을 줄이면서 AI를 업무에 적용할 수 있습니다. 이후 데이터가 쌓이면 자주 나오는 문의, 배송 문제, 상품 불만을 리포트로 만들어 CS와 운영 개선까지 연결할 수 있습니다."
